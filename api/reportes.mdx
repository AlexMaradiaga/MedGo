Los endpoints de reportes y dashboards proporcionan a los administradores de MedCore Global acceso a estadísticas operativas en tiempo real, analítica de inteligencia de negocio (BI), indicadores de calidad clínica y exportación de reportes ejecutivos en formato PDF. Todos los endpoints requieren autenticación mediante **Bearer token** en el header `Authorization`. Salvo indicación contraria, se requiere rol de **Administrador**.

---

## GET /api/reports/dashboard

<Note>Rol requerido: **Administrador**</Note>

Devuelve las estadísticas globales de la plataforma para el dashboard principal del administrador. Incluye métricas de pacientes, citas, tasas de cancelación, ingresos estimados y el índice de ausentismo por médico.

### Respuesta exitosa `200 OK`

```json
{
  "total_pacientes": 1248,
  "total_citas": 3872,
  "tasa_cancelacion": 8.4,
  "ingresos_estimados": 142600.00,
  "no_shows_por_medico": [
    {
      "DoctorID": 14,
      "doctor_nombre": "Dr. Carlos Méndez",
      "no_shows": 5
    },
    {
      "DoctorID": 22,
      "doctor_nombre": "Dra. Ana Torres",
      "no_shows": 2
    }
  ]
}
```

### Campos de respuesta

<ResponseField name="total_pacientes" type="integer">
  Número total de pacientes registrados en la plataforma.
</ResponseField>

<ResponseField name="total_citas" type="integer">
  Número total de citas médicas registradas en el período activo.
</ResponseField>

<ResponseField name="tasa_cancelacion" type="number">
  Porcentaje de citas canceladas sobre el total de citas registradas en el período.
</ResponseField>

<ResponseField name="ingresos_estimados" type="number">
  Suma estimada de ingresos generados por consultas pagadas en el período.
</ResponseField>

<ResponseField name="no_shows_por_medico" type="array">
  Lista de médicos con el número de citas en las que el paciente no se presentó (no-show) en el período.
</ResponseField>

### Ejemplo de solicitud

```bash
curl -X GET https://tu-instancia.com/api/reports/dashboard \
  -H "Authorization: Bearer {token}"
```

## GET /api/reports/appointments

<Note>Rol requerido: **Cualquier rol autenticado**</Note>

Devuelve un reporte filtrado de citas médicas. Los parámetros de filtro son opcionales; si se omiten, devuelve todas las citas disponibles según el rol del usuario autenticado.

### Parámetros de consulta

<ParamField query="fecha_inicio" type="string">
  Fecha de inicio del rango de búsqueda. Formato: `YYYY-MM-DD`.

  Ejemplo: `"2026-01-01"`
</ParamField>

<ParamField query="fecha_fin" type="string">
  Fecha de fin del rango de búsqueda. Formato: `YYYY-MM-DD`.

  Ejemplo: `"2026-03-31"`
</ParamField>

<ParamField query="DoctorID" type="integer">
  Filtra las citas por un médico específico.
</ParamField>

### Respuesta exitosa `200 OK`

```json
[
  {
    "CitaID": 487,
    "FechaHora": "2026-03-15T09:30:00",
    "EstadoCita": "Completada",
    "entidad_nombre": "Clínica Central MedCore",
    "doctor_nombre": "Dr. Carlos Méndez",
    "paciente_nombre": "María López"
  },
  {
    "CitaID": 491,
    "FechaHora": "2026-03-15T11:00:00",
    "EstadoCita": "Cancelada",
    "entidad_nombre": "Sucursal Norte",
    "doctor_nombre": "Dra. Ana Torres",
    "paciente_nombre": "Juan Pérez"
  }
]
```

### Ejemplo de solicitud

```bash
curl -X GET "https://tu-instancia.com/api/reports/appointments?fecha_inicio=2026-01-01&fecha_fin=2026-03-31&DoctorID=14" \
  -H "Authorization: Bearer {token}"
```

## GET /api/admin/reports/analytics

<Note>Rol requerido: **Administrador**</Note>

Devuelve el reporte completo de analítica de inteligencia de negocio (BI) de la plataforma. Agrupa cinco conjuntos de datos para análisis avanzado: embudo de conversión, desempeño por médico, demografía de pacientes, mapa de calor de demanda y evolución mensual.

### Respuesta exitosa `200 OK`

```json
{
  "funnel": {
    "agendadas": 420,
    "confirmadas": 389,
    "completadas": 350,
    "canceladas": 35,
    "no_shows": 14
  },
  "profesionales": [
    {
      "DoctorID": 14,
      "doctor_nombre": "Dr. Carlos Méndez",
      "total_consultas": 128,
      "ingresos_generados": 8320.00,
      "tasa_satisfaccion": 94.5
    }
  ],
  "pacientes": {
    "nuevos_mes": 42,
    "recurrentes": 308,
    "distribucion_edad": {
      "18-30": 120,
      "31-50": 210,
      "51+": 88
    }
  },
  "heatmap": [
    {"dia": "Lunes", "hora": "09:00", "demanda": 32},
    {"dia": "Lunes", "hora": "10:00", "demanda": 45},
    {"dia": "Viernes", "hora": "17:00", "demanda": 8}
  ],
  "evolucion": [
    {"mes": "2026-01", "citas": 310, "ingresos": 20150.00},
    {"mes": "2026-02", "citas": 348, "ingresos": 22620.00},
    {"mes": "2026-03", "citas": 372, "ingresos": 24180.00}
  ]
}
```

### Campos de respuesta

<ResponseField name="funnel" type="object">
  Embudo de conversión de citas: desde el agendamiento hasta la completación, con desglose de cancelaciones y ausentismos.
</ResponseField>

<ResponseField name="profesionales" type="array">
  Métricas de desempeño por médico: número de consultas, ingresos generados y tasa de satisfacción del paciente.
</ResponseField>

<ResponseField name="pacientes" type="object">
  Estadísticas demográficas y de captación de pacientes: nuevos en el mes, recurrentes y distribución por rango de edad.
</ResponseField>

<ResponseField name="heatmap" type="array">
  Mapa de calor de demanda de citas por día de la semana y franja horaria. Útil para optimizar la disponibilidad del médico.
</ResponseField>

<ResponseField name="evolucion" type="array">
  Datos de evolución mensual de citas e ingresos para análisis de tendencias históricas.
</ResponseField>

## GET /api/admin/indicadores-calidad

<Note>Rol requerido: **Administrador**</Note>

Devuelve los indicadores clave de calidad clínica y operativa de la plataforma, agrupados en tres categorías de auditoría: seguridad del paciente, eficiencia operativa y relaciones con el paciente.

### Respuesta exitosa `200 OK`

```json
{
  "seguridad": {
    "eventos_adversos": 2,
    "tasa_readmision": 1.8,
    "alertas_alergias_activas": 5
  },
  "eficiencia": {
    "tiempo_promedio_consulta_min": 22,
    "tasa_ocupacion_agenda": 87.4,
    "tiempo_espera_promedio_min": 11
  },
  "relaciones_pacientes": {
    "nps": 72,
    "quejas_registradas": 3,
    "tasa_retencion": 91.2
  }
}
```

### Campos de respuesta

<ResponseField name="seguridad" type="object">
  Indicadores de seguridad clínica: eventos adversos reportados, tasa de readmisión y alertas de alergias activas.
</ResponseField>

<ResponseField name="eficiencia" type="object">
  Indicadores de eficiencia operativa: tiempo promedio de consulta, porcentaje de ocupación de la agenda y tiempo de espera promedio del paciente.
</ResponseField>

<ResponseField name="relaciones_pacientes" type="object">
  Indicadores de satisfacción y fidelización: NPS (Net Promoter Score), quejas formales registradas y tasa de retención de pacientes.
</ResponseField>

## GET /api/admin/reportes/exportar

<Note>Rol requerido: **Administrador**</Note>

Exporta un reporte ejecutivo en formato PDF o JSON según el tipo seleccionado. Los reportes en PDF contienen visualizaciones, tablas de datos y análisis listos para presentaciones ejecutivas.

### Parámetros de consulta

<ParamField query="tipo" type="string" required>
  Tipo de reporte a exportar. Valores permitidos:

  | Valor          | Descripción                                                   | Formato   |
  |----------------|---------------------------------------------------------------|-----------|
  | `general`      | Reporte general de operaciones de la clínica.                 | PDF       |
  | `seguridad`    | Reporte de indicadores de seguridad clínica.                  | PDF       |
  | `eficiencia`   | Reporte de eficiencia operativa y tiempos de atención.        | PDF       |
  | `paciente`     | Reporte de demografía y comportamiento de pacientes.          | PDF       |
  | `saas-general` | Reporte general de uso de la plataforma SaaS.                 | JSON      |
  | `saas-plan`    | Reporte de distribución y estado de planes de suscripción.    | JSON      |
</ParamField>

### Respuesta exitosa `200 OK`

Para tipos `general`, `seguridad`, `eficiencia` y `paciente`, la respuesta es un archivo binario PDF con el header `Content-Type: application/pdf`.

Para tipos `saas-general` y `saas-plan`, la respuesta es un objeto JSON con los datos del reporte.

### Ejemplo: Descargar reporte en PDF

```bash
curl -X GET "https://tu-instancia.com/api/admin/reportes/exportar?tipo=general" \
  -H "Authorization: Bearer {token}" \
  -H "Accept: application/pdf" \
  --output reporte-general.pdf
```

### Ejemplo: Obtener reporte SaaS en JSON

```bash
curl -X GET "https://tu-instancia.com/api/admin/reportes/exportar?tipo=saas-general" \
  -H "Authorization: Bearer {token}" \
  -H "Accept: application/json"
```

## GET /api/admin/saas/monitoreo

<Note>Rol requerido: **Administrador**</Note>

Devuelve los indicadores de monitoreo del modelo de negocio SaaS de la plataforma: ingresos recurrentes mensuales (MRR), suscriptores activos, contratos próximos a vencer y distribución de planes contratados.

### Respuesta exitosa `200 OK`

```json
{
  "mrr": 12400.00,
  "suscriptores_activos": 38,
  "proximos_a_vencer": [
    {
      "EntidadID": 5,
      "entidad_nombre": "Clínica San Rafael",
      "plan": "Pro",
      "fecha_vencimiento": "2026-04-10"
    },
    {
      "EntidadID": 12,
      "entidad_nombre": "Centro Médico del Valle",
      "plan": "Starter",
      "fecha_vencimiento": "2026-04-18"
    }
  ],
  "distribucion_planes": [
    {
      "plan": "Starter",
      "cantidad": 14,
      "porcentaje": 36.8
    },
    {
      "plan": "Pro",
      "cantidad": 18,
      "porcentaje": 47.4
    },
    {
      "plan": "Enterprise",
      "cantidad": 6,
      "porcentaje": 15.8
    }
  ]
}
```

### Campos de respuesta

<ResponseField name="mrr" type="number">
  Monthly Recurring Revenue (MRR): total de ingresos recurrentes mensuales generados por todas las suscripciones activas.
</ResponseField>

<ResponseField name="suscriptores_activos" type="integer">
  Número de entidades o clínicas con suscripción activa en la plataforma.
</ResponseField>

<ResponseField name="proximos_a_vencer" type="array">
  Lista de suscripciones cuya fecha de vencimiento está dentro de los próximos 30 días, con entidad, plan y fecha exacta de expiración.
</ResponseField>

<ResponseField name="distribucion_planes" type="array">
  Desglose de suscriptores activos por tipo de plan, con cantidad y porcentaje del total.
</ResponseField>

### Ejemplo de solicitud

```bash
curl -X GET https://tu-instancia.com/api/admin/saas/monitoreo \
  -H "Authorization: Bearer {token}"
```
