MedGo\+ opera bajo un modelo de Software as a Service (SaaS) en el que cada entidad —clínica, laboratorio o farmacia— contrata un plan de acceso que define los límites y capacidades de la plataforma para su operación. Como administrador, tienes visibilidad completa sobre el estado de todas las suscripciones activas, las entidades próximas a vencer y los ingresos recurrentes mensuales generados por la plataforma.

<Info>
  El **Plan Gratuito** impone un límite de **10 pacientes activos** para la entidad suscrita. Una vez alcanzado este límite, el sistema bloqueará el registro de nuevos pacientes hasta que la entidad actualice su plan. Para eliminar esta restricción, actualiza la entidad al Plan Premium.
</Info>

## Planes disponibles

MedCore Global ofrece dos niveles de suscripción para entidades:

<CardGroup cols={2}>
  <Card title="Plan Gratuito" icon="circle">
    **Ideal para:** Clínicas en etapa de evaluación o con volumen reducido de atención.

    - Acceso completo a los módulos de la plataforma
    - Límite de **10 pacientes activos**
    - Sin costo mensual
    - Soporte vía documentación y comunidad
  </Card>

  <Card title="Plan Premium" icon="star">
    **Ideal para:** Clínicas y laboratorios en operación con demanda creciente.

    - Acceso completo a todos los módulos
    - Pacientes **ilimitados**
    - Reportes ejecutivos y exportación avanzada
    - Soporte prioritario con SLA garantizado
  </Card>
</CardGroup>

## KPIs de suscripción

Monitorea en tiempo real el desempeño financiero y operativo de las suscripciones activas en la plataforma.

```http
GET /api/admin/saas/monitoreo
```

**Respuesta de ejemplo:**

```json
{
  "status": "success",
  "data": {
    "kpis": {
      "MRR": 4850.00,
      "PremiumActivos": 38,
      "PlanesGratis": 11,
      "PorVencer": 4
    },
    "suscripciones": [
      {
        "EntidadID": 7,
        "NombreEntidad": "Clínica del Valle",
        "FechaVencimiento": "2026-02-05",
        "Plan": "Premium"
      },
      {
        "EntidadID": 12,
        "NombreEntidad": "Lab Diagnóstico Norte",
        "FechaVencimiento": "2026-02-10",
        "Plan": "Premium"
      }
    ],
    "transacciones": []
  }
}
```

| Campo | Descripción |
| --- | --- |
| `MRR` | Monthly Recurring Revenue: ingreso recurrente mensual total generado por todos los planes activos. |
| `PremiumActivos` | Número de entidades con plan Premium vigente. |
| `PlanesGratis` | Número de entidades activas en el plan gratuito. |
| `PorVencer` | Número de suscripciones que vencen en los próximos 30 días. |
| `suscripciones` | Listado de entidades con suscripción próxima a vencer, ordenado por fecha de vencimiento. |
| `transacciones` | Historial de los pagos de suscripción más recientes registrados en la plataforma. |

## Actualizar el plan de una entidad

Asigna o actualiza el plan de suscripción de una entidad específica. Esta acción registra el pago correspondiente y activa los nuevos límites de forma inmediata.

```http
POST /api/admin/saas/actualizar-plan
```

**Cuerpo de la solicitud:**

```json
{
  "tipo_plan": "Premium",
  "dias_vigencia": 30,
  "token_pasarela": "tok_visa_abc123xyz"
}
```

| Campo | Tipo | Requerido | Descripción |
| --- | --- | --- | --- |
| `tipo_plan` | `string` | ✅ | Nombre del plan a asignar. Valores aceptados: `Gratuito`, `Premium`. |
| `dias_vigencia` | `integer` | ✅ | Duración de la suscripción en días a partir de la fecha de activación. |
| `token_pasarela` | `string` | ✅ | Token de transacción emitido por la pasarela de pago al procesar el cobro. |

**Respuesta exitosa:** `200 OK` con confirmación de que el plan fue modificado y el historial de pago registrado.

## Gestionar precios de servicios

Define o actualiza el precio de servicios médicos específicos para un doctor determinado. Esto permite personalizar tarifas de consulta y procedimientos según los acuerdos comerciales de cada profesional dentro de la plataforma.

```http
POST /api/admin/servicios/tarifa
```

**Cuerpo de la solicitud:**

```json
{
  "servicio_id": 15,
  "doctor_id": 8,
  "nombre_servicio": "Consulta General",
  "precio": 450.00,
  "estado": true
}
```

| Campo | Tipo | Requerido | Descripción |
| --- | --- | --- | --- |
| `servicio_id` | `integer` | ❌ | Identificador del servicio existente a actualizar. Omitir para crear un nuevo servicio. |
| `doctor_id` | `integer` | ✅ | Identificador del doctor al que aplica la tarifa. |
| `nombre_servicio` | `string` | ✅ | Nombre descriptivo del servicio o tipo de consulta (máximo 100 caracteres). |
| `precio` | `decimal` | ✅ | Precio base del servicio para este doctor. |
| `estado` | `boolean` | ✅ | `true` para activar el servicio; `false` para desactivarlo del catálogo. |

**Respuesta exitosa:** `200 OK` con confirmación de que la tarifa fue guardada.

## Exportar reportes de suscripción

Genera y descarga reportes de facturación y estado de planes activos para análisis externo o presentación a directivos.

```http
GET /api/admin/reportes/exportar?tipo={tipo}
```

Los tipos de reporte disponibles son:

| Tipo (`tipo`) | Descripción |
| --- | --- |
| `general` | Resumen integral de actividad de todas las entidades: citas, pacientes, ingresos y personal. |
| `por-plan` | Desglose de entidades agrupadas por plan de suscripción, con MRR y detalle de facturación por categoría de plan. |

**Ejemplo para el reporte general:**

```http
GET /api/admin/reportes/exportar?tipo=general
```

**Ejemplo para el reporte desglosado por plan:**

```http
GET /api/admin/reportes/exportar?tipo=por-plan
```
