MedCore Global opera bajo un modelo de Software as a Service (SaaS) en el que cada entidad —clínica, laboratorio o farmacia— contrata un plan de acceso que define los límites y capacidades de la plataforma para su operación. Como administrador, tienes visibilidad completa sobre el estado de todas las suscripciones activas, las entidades próximas a vencer y los ingresos recurrentes mensuales generados por la plataforma.

<Info>
  El **Plan Gratuito** impone un límite estricto de **10 pacientes activos** a nivel de plataforma para la entidad suscrita. Una vez alcanzado este límite, el sistema bloqueará el registro de nuevos pacientes hasta que la entidad actualice su plan o elimine registros existentes. Esta restricción aplica de forma global y no puede ser sobrepasada mediante ninguna configuración manual.
</Info>

## Planes disponibles

MedCore Global ofrece dos niveles de suscripción para entidades:

<CardGroup cols={2}>
  <Card title="Plan Gratuito" icon="circle">
    **Ideal para:** Clínicas en etapa de evaluación o con volumen reducido de atención.

    - Acceso completo a los módulos de la plataforma
    - Límite de **10 pacientes activos**
    - Sin costo mensual
    - Soporte vía documentación y comunidad
  </Card>
  <Card title="Plan Premium" icon="star">
    **Ideal para:** Clínicas y laboratorios en operación con demanda creciente.

    - Acceso completo a todos los módulos
    - Pacientes **ilimitados**
    - Reportes ejecutivos y exportación avanzada
    - Soporte prioritario con SLA garantizado
  </Card>
</CardGroup>

## KPIs de suscripción

Monitorea en tiempo real el desempeño financiero y operativo de las suscripciones activas en la plataforma.

```http
GET /api/admin/saas/monitoreo
```

**Respuesta de ejemplo:**

```json
{
  "MRR": 4850.00,
  "SuscriptoresActivos": 49,
  "ProximasAVencer": [
    {
      "EntidadID": 7,
      "NombreEntidad": "Clínica del Valle",
      "FechaVencimiento": "2026-02-05",
      "Plan": "Premium"
    },
    {
      "EntidadID": 12,
      "NombreEntidad": "Lab Diagnóstico Norte",
      "FechaVencimiento": "2026-02-10",
      "Plan": "Premium"
    }
  ]
}
```

| Campo | Descripción |
|---|---|
| `MRR` | Monthly Recurring Revenue: ingreso recurrente mensual total generado por todos los planes activos. |
| `SuscriptoresActivos` | Número de entidades con suscripción vigente en el período actual. |
| `ProximasAVencer` | Lista de entidades cuya suscripción vence en los próximos 30 días, ordenada por fecha de vencimiento. |

## Actualizar el plan de una entidad

Asigna o actualiza el plan de suscripción de una entidad específica. Esta acción registra el pago correspondiente y activa los nuevos límites de forma inmediata.

```http
POST /api/admin/saas/actualizar-plan
```

**Cuerpo de la solicitud:**

```json
{
  "EntidadID": 3,
  "PlanID": 2,
  "MetodoPago": "Transferencia",
  "Monto": 99.00
}
```

| Campo | Tipo | Requerido | Descripción |
|---|---|---|---|
| `EntidadID` | `integer` | ✅ | Identificador de la entidad cuyo plan se actualiza. |
| `PlanID` | `integer` | ✅ | Identificador del plan a asignar. `1` = Gratuito, `2` = Premium. |
| `MetodoPago` | `string` | ✅ | Método de pago registrado. Valores aceptados: `Transferencia`, `TarjetaCredito`, `TarjetaDebito`, `Efectivo`. |
| `Monto` | `decimal` | ✅ | Monto cobrado en la transacción. Debe coincidir con el precio del plan seleccionado. |

**Respuesta exitosa:** `200 OK` con la confirmación del plan activado, fecha de inicio y fecha de próximo vencimiento.

## Gestionar precios de servicios

Define o actualiza el precio de servicios específicos para una entidad determinada. Esto permite personalizar tarifas según acuerdos comerciales, ubicación geográfica o tipo de entidad.

```http
POST /api/admin/servicios/tarifa
```

**Cuerpo de la solicitud:**

```json
{
  "EntidadID": 3,
  "ServicioID": 15,
  "Precio": 450.00,
  "Moneda": "HNL"
}
```

| Campo | Descripción |
|---|---|
| `EntidadID` | Entidad a la que aplica la tarifa personalizada. |
| `ServicioID` | Identificador del servicio o tipo de consulta en el catálogo. |
| `Precio` | Precio base del servicio para esta entidad. |
| `Moneda` | Código de moneda ISO 4217. Por defecto: `HNL` (Lempira hondureño). |

## Exportar reportes de suscripción

Genera y descarga el reporte detallado de facturación y estado de planes activos para análisis externo o presentación a directivos.

```http
GET /api/admin/reportes/exportar?tipo=saas-plan
```

El reporte `saas-plan` incluye:

- Listado de todas las entidades y su plan actual
- Fecha de inicio y vencimiento de cada suscripción
- Monto facturado y método de pago registrado
- MRR desglosado por tipo de plan
- Proyección de renovaciones para los próximos 60 días

Para un reporte de mayor alcance que incluya métricas generales de todas las suscripciones sin desglose por plan, utiliza `tipo=saas-general`.

```http
GET /api/admin/reportes/exportar?tipo=saas-general
```
