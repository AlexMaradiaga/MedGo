Agendar una cita en MedCore Global es rápido y sencillo, ya sea desde el portal web o mediante la API. Puedes buscar médicos por especialidad, ver su disponibilidad en tiempo real, seleccionar la clínica de tu preferencia y confirmar tu reserva en minutos. Esta guía explica cómo hacerlo paso a paso desde el portal, cómo usar la API para integraciones avanzadas y cómo gestionar reagendamientos y cancelaciones.

---

## Agendar desde el portal web

<Steps>
  <Step title="Buscar médico">
    Ingresa al portal y dirígete a la sección **Directorio Médico** en el menú principal. Usa el filtro de **Especialidad** para acotar los resultados (por ejemplo, Medicina General, Cardiología, Pediatría). También puedes buscar directamente por nombre del médico. Haz clic en el perfil del médico que deseas consultar para ver su información, clínicas donde atiende y calificaciones de otros pacientes.
  </Step>
  <Step title="Seleccionar fecha y hora">
    Dentro del perfil del médico, encontrarás el **Calendario de Disponibilidad**. Los bloques en verde indican horarios disponibles. Haz clic en el día y la hora que prefieras. El sistema solo muestra horarios que el médico ha habilitado para reservas en línea.
  </Step>
  <Step title="Confirmar datos del paciente">
    La plataforma precargará automáticamente tu nombre, DNI y datos de seguro médico. Revisa que toda la información sea correcta y, si la cita es para un **dependiente**, selecciónalo desde el menú desplegable **¿Para quién es la cita?**. Completa el campo **Motivo de consulta** y añade los síntomas que estás experimentando.
  </Step>
  <Step title="Seleccionar clínica">
    Si el médico atiende en más de una clínica, se mostrará una lista con las opciones disponibles para la fecha seleccionada. Elige la clínica más conveniente para ti. Puedes ver la dirección y un enlace a Google Maps directamente en esta pantalla.
  </Step>
  <Step title="Confirmar y pagar">
    Revisa el resumen completo de tu cita: médico, especialidad, clínica, fecha, hora y costo de la consulta. Si tienes seguro médico, el sistema calculará el copago correspondiente. Haz clic en **Confirmar Cita** y completa el pago si aplica. Recibirás una notificación por correo electrónico y dentro de la plataforma una vez que el médico apruebe la reserva.
  </Step>
</Steps>

<Warning>
  Tu cita **no queda confirmada automáticamente** al completar el formulario. El médico o su asistente deben aprobar la solicitud de reserva. Recibirás una notificación por correo electrónico y en la app cuando la cita sea aprobada o rechazada. Te recomendamos agendar con al menos 24 horas de anticipación para dar tiempo a la aprobación.
</Warning>

## Agendar via API

Si estás integrando MedCore Global con otra aplicación o deseas automatizar el agendamiento, utiliza el siguiente endpoint:

```
POST /api/citas
```

### Cuerpo de la solicitud

```json
{
  "DoctorID": 5,
  "PacienteID": 12,
  "EntidadID": 3,
  "FechaHora": "2026-02-15T10:00:00",
  "Motivo": "Dolor de cabeza persistente",
  "Sintomas": "Cefalea, mareos",
  "Alergias": "Penicilina",
  "MedicamentosActuales": "Ninguno",
  "EnfermedadesCronicas": [1, 3]
}
```

| Campo                  | Tipo       | Requerido | Descripción                                                                 |
|------------------------|------------|-----------|-----------------------------------------------------------------------------|
| `DoctorID`             | `integer`  | ✅        | ID del médico con quien deseas la cita.                                     |
| `PacienteID`           | `integer`  | ✅        | Tu `patient_id` o el del dependiente para quien agendas.                    |
| `EntidadID`            | `integer`  | ✅        | ID de la clínica u hospital donde se realizará la consulta.                 |
| `FechaHora`            | `string`   | ✅        | Fecha y hora en formato ISO 8601 (`YYYY-MM-DDTHH:MM:SS`).                   |
| `Motivo`               | `string`   | ✅        | Descripción breve del motivo de la consulta.                                |
| `Sintomas`             | `string`   | ❌        | Síntomas actuales, separados por comas.                                     |
| `Alergias`             | `string`   | ❌        | Alergias conocidas a medicamentos u otras sustancias.                       |
| `MedicamentosActuales` | `string`   | ❌        | Medicamentos que el paciente está tomando actualmente.                      |
| `EnfermedadesCronicas` | `array`    | ❌        | Lista de IDs de enfermedades crónicas del catálogo de la plataforma.        |

### Respuesta exitosa

```json
{
  "status": "success",
  "code": 201,
  "data": {
    "cita_id": 88,
    "estado": "Pendiente de aprobación",
    "fecha_hora": "2026-02-15T10:00:00"
  }
}
```

<Tip>
  El campo `EnfermedadesCronicas` recibe un arreglo de IDs numéricos del catálogo oficial de la plataforma. Para obtener la lista completa de condiciones disponibles junto con sus IDs, consulta el endpoint `GET /api/enfermedades-cronicas`. Incluir esta información ayuda al médico a prepararse mejor para tu consulta.
</Tip>

## Reagendar una cita

Si necesitas cambiar la fecha u hora de una cita existente, usa el siguiente endpoint:

```
PUT /api/citas/{id}/reprogramar
```

Reemplaza `{id}` con el `cita_id` de la cita que deseas reagendar.

### Cuerpo de la solicitud

```json
{
  "nueva_fecha": "2026-02-20T14:30:00"
}
```

El médico deberá aprobar nuevamente la nueva fecha propuesta. El estado de la cita volverá a **Pendiente de aprobación** hasta recibir confirmación.

---

## Cancelar una cita

Para cancelar una cita, realiza la siguiente solicitud:

```
DELETE /api/citas/{id}
```

Reemplaza `{id}` con el `cita_id` de la cita a cancelar. Si la cita ya fue aprobada, la cancelación puede estar sujeta a la política de cancelación del médico o la clínica. Recibirás un correo de confirmación cuando la cancelación sea procesada.

### Respuesta exitosa

```json
{
  "status": "success",
  "message": "La cita ha sido cancelada exitosamente."
}
```

## Ver mis citas

Para consultar el historial completo de tus citas (pasadas, pendientes y confirmadas), usa el siguiente endpoint:

```
GET /api/citas/historial/{usuarioId}
```

Reemplaza `{usuarioId}` con tu `user_id`. La respuesta incluye para cada cita: el nombre del médico, la especialidad, la clínica, la fecha y hora, el estado actual (`Pendiente`, `Confirmada`, `Completada`, `Cancelada`) y el motivo de consulta registrado.

También puedes ver tus próximas citas directamente en el portal web desde la sección **Mis Citas** en el menú principal, donde encontrarás recordatorios y la opción de añadir la cita a tu calendario personal.
