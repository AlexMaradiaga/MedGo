Bienvenido a MedGo\+. Antes de agendar citas, acceder a tu historial clínico o descargar recetas, necesitas crear tu cuenta de paciente. El proceso tarda menos de cinco minutos y solo requiere tu documento de identidad, un correo electrónico válido y tu información básica de contacto. Esta guía cubre los tres escenarios de registro: paciente adulto autónomo, tutor que registra su propio perfil clínico y registro de un menor como dependiente.

---

## Registro de paciente adulto

Si eres mayor de edad y deseas crear tu propia cuenta, realiza una solicitud `POST` al siguiente endpoint:

```text
POST /api/register-patient
```

### Cuerpo de la solicitud

```json
{
  "nombre": "Carlos",
  "apellido": "López",
  "email": "carlos@ejemplo.com",
  "password": "MiClave123!",
  "dni": "0801-1990-12345",
  "telefono": "+504 9888-0000",
  "entidad_id": 1
}
```

| Campo | Tipo | Requerido | Descripción |
| --- | --- | --- | --- |
| `nombre` | `string` | ✅ | Primer nombre del paciente. |
| `apellido` | `string` | ✅ | Apellido del paciente. |
| `email` | `string` | ✅ | Correo electrónico único para inicio de sesión. |
| `password` | `string` | ✅ | Contraseña (mínimo 6 caracteres). |
| `dni` | `string` | ✅ | Documento Nacional de Identidad. Debe ser único en el sistema. |
| `telefono` | `string` | ❌ | Número de teléfono con código de país. |
| `entidad_id` | `integer` | ✅ | ID de la clínica u hospital al que pertenecerá tu cuenta. |

### Respuesta exitosa

```json
{
  "status": "success",
  "message": "Paciente registrado correctamente en MedGo+"
}
```

<Note>
  El campo `dni` debe ser único en toda la plataforma. Si intentas registrarte con un DNI ya existente, recibirás un error `422 Unprocessable Entity`. Si crees que ya tienes una cuenta, usa la opción **¿Olvidaste tu contraseña?** en la pantalla de inicio de sesión.
</Note>

<Tip>
  Asegúrate de ingresar un correo electrónico al que tengas acceso inmediato. MedCore Global envía a esa dirección las confirmaciones de citas, las recetas digitales y las notificaciones de resultados de laboratorio.
</Tip>

## Registro como tutor

Si eres el tutor legal de un menor y también deseas registrar tu propio perfil clínico en el sistema (por ejemplo, para tener acceso a tus propias consultas y recetas), utiliza el endpoint de auto-registro:

```text
POST /api/pacientes/auto-registro
```

Este endpoint crea un perfil de paciente vinculado a tu cuenta de usuario existente. Es el paso necesario para que un usuario con rol de tutor también tenga un expediente médico propio dentro de la plataforma.

### Cuerpo de la solicitud

```json
{
  "DNI": "0501-1985-67890",
  "Nombre": "María",
  "Apellido": "González",
  "Telefono": "+504 9777-1111"
}
```

| Campo | Tipo | Requerido | Descripción |
| --- | --- | --- | --- |
| `DNI` | `string` | ✅ | Documento de identidad del tutor. |
| `Nombre` | `string` | ✅ | Primer nombre del tutor. |
| `Apellido` | `string` | ✅ | Apellido del tutor. |
| `Telefono` | `string` | ✅ | Número de teléfono de contacto. |

### Respuesta exitosa

```json
{
  "status": "success",
  "message": "Tu perfil clínico individual ha sido creado con éxito."
}
```

Una vez completado, tendrás un perfil de paciente asociado a tu cuenta de tutor, lo que te permitirá usar la plataforma tanto para gestionar la salud de tus dependientes como para la tuya propia.

## Dependientes

Los menores de edad o personas bajo tutela legal pueden ser registrados dentro de la cuenta de su tutor como **dependientes**. Al crear el perfil de un menor, incluye el parámetro `es_dependiente: true` y los datos del tutor responsable.

```json
{
  "nombre": "Sofía",
  "apellido": "González",
  "dni": "0501-2018-11111",
  "entidad_id": 1,
  "es_dependiente": true,
  "tutor_dni": "0501-1985-67890",
  "tutor_nombre": "María",
  "tutor_email": "maria@ejemplo.com",
  "tutor_telefono": "+504 9777-1111",
  "documento_identidad_url": "https://almacenamiento.ejemplo.com/docs/identidad-sofia.pdf"
}
```

| Campo | Tipo | Requerido | Descripción |
| --- | --- | --- | --- |
| `nombre` | `string` | ✅ | Nombre del menor. |
| `apellido` | `string` | ✅ | Apellido del menor. |
| `dni` | `string` | ✅ | Documento de identidad del menor. |
| `entidad_id` | `integer` | ✅ | ID de la clínica u hospital al que pertenecerá el perfil. |
| `es_dependiente` | `boolean` | ✅ | Debe ser `true` para registrar al paciente como dependiente. |
| `tutor_dni` | `string` | ✅ | DNI del tutor legal. |
| `tutor_nombre` | `string` | ✅ | Nombre del tutor legal. |
| `tutor_email` | `string` | ✅ | Correo electrónico del tutor legal. |
| `tutor_telefono` | `string` | ✅ | Teléfono del tutor legal. |
| `documento_identidad_url` | `string` | ✅ | URL del documento de identidad del menor ya cargado. |

Los dependientes **no tienen credenciales de acceso propias**. El tutor gestiona sus citas, historial, recetas y órdenes de laboratorio desde su propia sesión. En el portal web, encontrarás la sección **Mis dependientes** en el menú de tu perfil para añadir, editar o consultar la información de cada uno.

## Emancipar un dependiente

Cuando un dependiente alcanza la mayoría de edad o adquiere capacidad legal para gestionar su propia salud, el tutor puede promoverlo a usuario autónomo mediante el siguiente endpoint:

```text
POST /api/pacientes/{id}/emancipar
```

Reemplaza `{id}` con el identificador del dependiente que deseas emancipar.

### Cuerpo de la solicitud

```json
{
  "email": "sofia.gonzalez@ejemplo.com",
  "password": "NuevaClave456!"
}
```

| Campo | Tipo | Requerido | Descripción |
| --- | --- | --- | --- |
| `email` | `string` | ✅ | Correo electrónico único para la nueva cuenta. |
| `password` | `string` | ✅ | Contraseña para la nueva cuenta (mínimo 6 caracteres). |

### Respuesta exitosa

```json
{
  "status": "success",
  "message": "El paciente ha sido promovido a usuario independiente con éxito."
}
```

Tras la emancipación, el dependiente obtiene credenciales propias y puede iniciar sesión en MedCore Global de forma autónoma. El historial clínico previo se conserva íntegramente y queda asociado al nuevo perfil independiente.
